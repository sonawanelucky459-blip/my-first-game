# ⚔️ Discrete Math Quest

A gamified web-based Discrete Mathematics ISE-2 project.

## Features
- 5 progressive worlds
- Logic, Sets, Relations, Combinatorics and Graph Theory
- Score, lives and coins
- Timer and progress bar
- Interactive MCQ challenges
- Mathematical explanations
- World unlocking
- Final ranking
- Responsive design

## Technologies
HTML5, CSS3 and JavaScript.

## Run
Open `index.html` in a browser, or use VS Code with Live Server.
